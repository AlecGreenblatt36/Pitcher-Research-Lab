What the cards mean

Win chances describe uncertainty, not a guarantee. The projected score is the average across 10,000 simulated games; it need not be a whole number. The actual score appears only after the final result reconciles.

Lineup updates

An early forecast uses a clearly marked projected lineup based on prior appearances and the currently active roster. Once official lineups arrive, a new version is saved. Earlier versions are never overwritten. A missing starter or insufficient roster information blocks the forecast rather than inventing a player.

Postseason limitation

Postseason games use the existing regular-season pitcher-removal and bullpen heuristics. There is no automatic runner in postseason extra innings. Runner speed, defense and rest retain the legacy assumptions; steals and wild pitches remain absent. This is not a claimed accuracy upgrade.

Input freshness

History used in the saved forecasts runs through: 2026-10-05. The daily refresh checks completed games through the previous Eastern-calendar day and reconciles plate appearances against official final feeds before accepting a date. Source snapshots and history revisions stay encrypted; original forecast inputs are never rewritten. A coverage gap blocks new forecasts. The initial seed history retains its previously disclosed, unverified historical publication vintages.

Timing and evidence

Checks run on GitHub Actions every 15 minutes. GitHub can delay or drop scheduled jobs; a check is not guaranteed to coincide with lineup publication. Late computations are withheld. A live score requires the saved forecast and its publication receipt to precede the actual first pitch. Historical replays never enter the live track record.

Scoring

The headline uses the last eligible, publicly saved pregame version for each game. Model and team baseline are scored on identical games. Brier has a finite-simulation correction. Log-loss correction is a second-order approximation. Monte Carlo numerical error is separate from uncertainty in model skill. Market comparisons remain unavailable without same-cutoff, margin-removed odds.

2025 replay

The current anchor used 2025 calibration data. A 2025 replay with this lock is development, not an out-of-sample accuracy test. A clean comparison requires an earlier frozen model or a newly specified temporal evaluation. The 2,430-game run has not been performed by this live deployment.
